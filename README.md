# Sprint_7

В этом проекте предстоит протестировать API учебного сервиса Яндекс Самокат https://qa-scooter.praktikum-services.ru/
## "Описание тестов"
1. Создание курьера. Ручка /api/v1/courier
- Тест- создание курьера.
- Тест- создание двух одинаковых курьеров.
- Тест- создание курьера, если одного из полей нет.

2. Создание заказа. Ручка /api/v1/orders
- Тест- при создании заказа можно выбрать разные вариации цвета самоката.

3. Логин курьера. Ручка /api/v1/courier/login
- Тест- курьер может авторизоваться, успешный запрос возвращает id
- Тест-попытка авторизации с пропуском одного из обязательных полей.
- Тест- авторизация курьера с неправильным логином.
- Тест- авторизация курьера с неправильным паролем.
- Тест- авторизация под несуществующим пользователем.

4. Список заказов. Ручка /api/v1/orders
- Тест- получение списка заказов

### Установка и запуск
1. Клонируйте репозиторий:

   ```bash
   git clone <URL вашего репозитория>
   cd Sprint_7
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Сгенерировать Allure-отчёт:

   ```bash
   pytest --alluredir=allure-results
